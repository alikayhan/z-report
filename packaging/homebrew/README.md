# Homebrew tap for Z Report

Install Z Report on an Apple Silicon Mac running macOS 13 or newer:

```sh
brew install --cask alikayhan/tap/z-report
```

The Cask installs the signed and notarized DMG published in
[z-report-releases](https://github.com/alikayhan/z-report-releases). Z Report
can update itself, or it can be upgraded through Homebrew:

```sh
brew upgrade --cask z-report
```

See the [public release documentation](https://github.com/alikayhan/z-report-releases)
for installation, update, uninstall, and privacy details.
