# Security

Z Report reads local Claude Code and Codex transcripts and sends an evidence package
to the evaluator you are signed in to. Anything that widens that boundary, leaks data
the Privacy settings say is withheld, or lets an update or plugin archive be swapped
for one that was not signed by the release pipeline is a security issue.

Report one privately through
[GitHub security advisories](https://github.com/alikayhan/z-report/security/advisories/new)
rather than a public issue. Expect an acknowledgement within a week. Fixes ship as a
regular release, and the advisory is published once the fix is available.

Only the latest release is supported. The installed app and the Claude Code mod both
update to it on confirmation.
